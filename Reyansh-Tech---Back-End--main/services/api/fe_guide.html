Global Integration Notes — read before you start

  • Send Authorization: Bearer <access_token> on every authenticated request. Token expires in 15 min — call POST /auth/refresh to rotate.
  • All list endpoints return { "data": [...], "meta": { "total", "page", "page_size", "pages" } }. Read response.data, not response.
  • Use user.org_type from login to pick the dashboard — not user.role. Mapping: PLATFORM→/admin · POLICE→/police · AMBULANCE→/ambulance · FIRE_DEPARTMENT→/fire.
  • user.role is the granular permission level (org_admin, operator, dispatcher, viewer) — use for feature gating, not routing.
  • All enum fields (severity, status, incident_type, org_type) are UPPERCASE. Call .toLowerCase() before display.
  • Incident status → OPEN=pending · ACKNOWLEDGED=acknowledged · RESPONDING=dispatched/on_route/on_scene · RESOLVED/CLOSED=completed.
  • Trip status → ACTIVE=Ongoing · COMPLETED=Completed · CANCELLED=Cancelled.
  • VehicleStateRead (from telemetry/latest) returns all fields as strings. Parse with parseFloat() before charting.
  • WebSocket: connect once per session at wss://api.reyanshtechnologies.com/ws/connect?token=<access_token>. Messages: { "type": "vehicle_state"|"incident_notification", "data": {...} }. Send a keepalive ping every 20 s.
  • CORS: localhost:3000, localhost:5173, and localhost:8080 are all allowed — no proxy needed during local development.
  • mac_address is a free-text field — no MAC format required. Avoid /, #, +, spaces.
  • There is no HOSPITAL org type — hospital pages remain on mock data.
Auth

Authentication

/login · /signup · /otp · /forgot

Login Page

/login
Swagger: auth ↗ ReDoc: auth ↗
After login, read user.org_type to route to the correct dashboard. Persist the entire user object (including org_name) for sidebar display.
Login form submit
Swagger ↗ ReDoc ↗
POST
/auth/login
Returns access_token, refresh_token, and user (user_id, email, name, org_id, org_type, org_name, role).
Body: { email, password }
Token refresh (call before access token expires)
Swagger ↗ ReDoc ↗
POST
/auth/refresh
Rotates both tokens. Always replace the stored pair with the new response.
Body: { refresh_token }
Logout
Swagger ↗ ReDoc ↗
POST
/auth/logout
Revokes both tokens. Pass access token in header, refresh token in body.
Header: Authorization: Bearer <token> · Body: { refresh_token }
Signup, OTP, and Forgot Password flows are not backed by the API yet — keep using mock/local logic.
